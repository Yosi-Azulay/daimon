daimon v0.9.0

Local dev-server manager for Angular / Nx / Vite / Storybook (+ polyglot) with a TUI, a 127.0.0.1 HTTP API, a JSON CLI, and an MCP server for Claude Code.

Install

npm install -g daimon
# or
npx daimon init --auto

Quickstart (3 min)

  1. Run daimon init --auto in a workspace that has nx.json / angular.json / vite.config.* / .storybook / manage.py / Gemfile.
  2. Run daimon list to see discovered apps.
  3. Run daimon start <app> (or daimon up <profile> for the whole stack).
  4. Open the dashboard: daimon dashboard.

CLI reference

lifecycle

daimon start <name> [--with-deps] [--steal]
Start an app. --steal overrides another agent's soft-lock.
daimon stop <name> [--steal]
Stop an app. --steal overrides another agent's soft-lock.
daimon restart <name> [--steal]
Restart an app. --steal overrides another agent's soft-lock.
daimon up [<profile>]
Start a profile (or autoStart). Waits for each to reach serving.
daimon down [<profile>]
Stop a profile (or all apps).
daimon run <name> <task> [--watch] [-- args...]
Run a discovered task.
daimon clean <name> [--deep] [--yes]
Remove build artifacts for an app.
daimon daemon start|stop|status|restart|attach|install-service [--detach] [--headless]
Manage the daimon daemon.

queries

daimon list [--tag <name>] [--workspace <label>] [--full|--compact] [--stream] [--explain]
List apps. Compact by default; --full for v0.4 shape; --stream for NDJSON; --explain wraps with _meta (searchRoots, scanned, rejected, suggestion).
daimon status <name> [--full|--compact]
Get the current status of one app. Compact by default.
daimon errors <name> [--since 2m] [--since-last] [--client <id>] [--structured] [--full|--compact]
Get deduplicated errors for an app. Compact by default ({file,line,col,code,message}).
daimon events [--since 1h] [--app <name>] [--stream]
Get the event log. --stream emits NDJSON until SIGINT.
daimon logs <name> [--tail N] [--since 30s]
Recent log lines for an app.
daimon history <name>
Summary metrics (uptime%, restarts, compile p50/p95, top errors).

agent verbs

daimon wait <name> [--until serving|healthy|stopped|error] [--timeout 60s]
Block until app reaches the given state.
daimon ensure <name> [--until serving|healthy] [--timeout 180s]
One-call: start if needed, block to target state, return terminal state. Idempotent.
daimon ensure-up <profile> [--until serving|healthy] [--timeout 300s]
One-call: cascade-start every app in the profile and wait for each to reach target.
daimon overview [--workspace <label>] [--profile <name>] [--budget <tokens>]
Decision-ready snapshot: totals, byStatus, needsAttention (with first parsed error), recentlyChanged. First call in a session. --budget caps the response size for agents; overflow collapses to _meta.omitted.
daimon focus <name> [--until serving|healthy|stable] [--timeout 180s]
One round-trip subscribe-then-act: streams NDJSON of status/error/url events for one app until target state or timeout. Designed for agents.
daimon try-fix <name> [--until serving|healthy] [--timeout 180s]
Composite: run doctor --auto-fix on permitted rules, restart the app, wait for target, return {before,after,fixed,stillFailing}. Never edits user source.
daimon orchestrate <profile> [--goal serving|healthy|stable] [--timeout 300s] [--dry-run] [--budget <tokens>]
Bring up a whole profile in one call: cascade-start, wait for goal, run ONE try-fix round on stragglers. Returns {profile, goal, perApp, totalMs, allReached}. --dry-run reports planned order only. Designed for agents.
daimon agents
List active agents touching this daemon and any current per-app soft-locks.
daimon handoff <app> <agentId>
Transfer the soft-lock on <app> to another agent.
daimon ci start <profile> [--until ready|healthy] [--timeout 5m] [--json]
CI helper: start a profile and block until all apps are healthy. Designed for GitHub Actions / Jenkins steps.

introspection

daimon why <name>
Last status transition + 5 preceding events.
daimon why-empty
Explain why `daimon list` is empty: configured searchRoots, scanned/rejected counts, suggested next step.
daimon discover [--dry-run]
Run discovery without changing state. Prints _meta: searchRoots, scanned, rejected per folder, suggestion.
daimon tasks <name>
List discovered non-serve tasks.
daimon snapshot <name>
Write a snapshot of app state to ~/.daimon/snapshots.
daimon record
Toggle session recording.
daimon replay <session.jsonl> [--speed N]
Replay a recorded session.
daimon doctor [--auto-fix] [--dry-run] [--self]
Sanity-check config + env. --auto-fix repairs orphan daemon, stale lock, missing search root, corrupt history db. --self checks daimon's own metrics.
daimon free-port <port> [--force]
Diagnose / free a port.
daimon self
Print daimon's own runtime metrics (pid, version, uptime, rss, heap, event-loop lag, history-db p95).
daimon dashboard
Open the dashboard in your default browser, scoped to the current cwd.
daimon timeline [--since 7d] [--app <name>] [--kinds status,error,warning,lint,bundle,task]
Print a unified chronological event timeline.

config

daimon pin-health <name> [--accept] [--path <p>]
Show the auto-discovered health-probe path for an app; --accept persists it as overrides.<name>.healthProbePath in daimon.config.json and soft-reloads. Default behaviour is opt-in: nothing is written without --accept.
daimon export-config [--redacted]
Emit the active config to stdout. --redacted replaces apiToken with "<redacted>" and rewrites home paths to ~/...
daimon env <name> [--use <file>]
List or set the active env file for an app.
daimon init [--force] [--auto]
Create a daimon config in cwd; --auto picks safe defaults (no prompts) for workspaces with nx/angular/vite markers.
daimon completion <bash|zsh|fish|powershell>
Emit a shell completion script for the given shell.
daimon workspaces list|add [path] [--label <name>] | rm <path> | show [path]
Manage the workspace registry (searchRoots).

claude

daimon claude install|update|uninstall|status [--skill] [--commands] [--agent] [--all] [--dir <path>] [--yes]
Install/update Claude Code integration artifacts.

plugin

daimon plugin list|show <name>|validate <path>
Manage doctor plug-ins.

MCP reference

Daimon's MCP server is installed via daimon claude install --all. It exposes the verbs below over stdio so Claude Code can call them.

list_apps
Compact list of apps (name/status/port/health/errCount/lastChangeMs).
list_apps_full
Verbose v0.4-shape list.
get_status
Compact status for one app.
get_status_full
Verbose status for one app.
get_errors
Errors for an app — supports --since, --since-last, --level.
get_logs
Recent log lines for an app.
start_app / stop_app / restart_app
Lifecycle verbs with cwd-scoped name resolution.
overview
Decision-ready snapshot for first-call agent sessions.
diff_errors
Errors since last call (per-client cursor).
try_fix
Run permitted auto-fixes, restart, wait for target.
focus
Subscribe-then-act stream of status/error events.
ensure
One-call lifecycle: start if needed, wait for target.
orchestrate
Bring up a whole profile; one round of try-fix on stragglers.
ensure_up
Cascade-start a profile, wait until each app is healthy.
wait_for_app
Block until app reaches a target state.
daimon_who_owns
Lock holder + last 3 agent interactions for an app.
daimon_subscribe_events
Long-poll new events filtered by kind.
daimon_notify_on_error
Block until next error-new event (or timeout).

Config reference

The full annotated schema lives in daimon.config.example.json. Highlights:

  • searchRoots — array of paths (or {path, label}) to scan for projects.
  • autoStart — apps to start when the daemon launches.
  • profiles — named sets of apps for daimon up <profile> / daimon ci start <profile>.
  • healthProbe — toggle and shape the per-app health probe.
  • webhooks — outbound notifications for error / regression / status events.
  • history — SQLite retention controls.

FAQ

Does daimon edit my code?
No. Daimon only touches ~/.daimon/* and (if you opt in) the local daimon.config.json. daimon doctor --auto-fix repairs daemon state, never source.
Is it safe to run two Claudes against one daemon?
Yes — every CLI call sends an X-Daimon-Agent header and the daemon enforces a 30-second per-app soft-lock so two agents don't fight. Pass --steal to override.
How do I get a notification when an app errors?
Configure a webhooks entry pointing at Slack/Discord, or call daimon_notify_on_error from MCP.
Can I use daimon in CI?
Yes — daimon ci start <profile> --until ready --timeout 5m --json returns a structured report and exits 2 on timeout. See docs/ci-integration.md.
